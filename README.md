# 英语能力测试 English Proficiency Test

按考生的**词汇量**自动生成一份英语能力测试卷，含四个部分：

- **Reading 阅读** — 2 篇文章 10 道单选，自动判分
- **Listening 听力** — 4 段材料 8 道单选，浏览器语音合成朗读，自动判分
- **Writing 写作** — 2 篇限时作答，实时字数统计
- **Speaking 口语** — 按题目录音后上传音频文件

题库分 A2 / B1 / B2 / C1 / C2 五个难度档，按输入的词汇量落位，
并从相邻档抽题做微调，让同一档内也能拉开区分度。
`试卷编号 + 词汇量` 作为随机种子，同样的输入永远生成同一份卷，便于复测与对照。

## 使用

打开网页 → 填考生姓名和词汇量 → 生成试卷 → 「复制考生链接」，
把链接发给考生，他打开就能直接开考。

考生链接参数：`?v=词汇量&code=试卷编号&name=姓名&w=写作题数&s=口语题数&p=听力播放次数`

## 本地运行

克隆后直接双击 `index.html` 即可（纯静态，无需构建、无需服务器）。
`node 构建单文件.mjs` 可把整站打包成一个自包含的 HTML 文件。

## 说明

- 听力依赖浏览器的英文语音包，建议用 Chrome 或 Edge。
- 阅读与听力自动判分；写作和口语提供 5 级评分标准表，由人工评分。
- 这是一个纯前端项目，题目与答案都在浏览器里，不适合高利害的正式考试。
